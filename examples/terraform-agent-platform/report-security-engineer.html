Method

Coverage gaps and accuracy notes

  • Collectors. checkov 3.4.5 (terraform, secrets) and semgrep p/terraform ran fresh on the clone; the fixture's committed out/ results were not used. SCA/SBOM, AI-BOM and SAST do not apply because there are no package manifests or app code. trufflehog was not installed; secrets came from semgrep.
  • Registry resolution was noisy. registry.resolve keyword matching mapped 5 of 8 IaC findings to unrelated LLM weaknesses (hardcoded RDS password → code_active_debug_code; SPIRE registration → llm_agent_cascading_hallucination; security group → SSN exfiltration). Those were rejected. The registry has no IaC-native weakness for hardcoded credentials, workload-identity misbinding or network exposure, so those findings stay keyed by CWE.
  • graph.enrich returned no paths and listed only 2 of the 4 regulated stores in reach. It dropped both PII+PCI stores, probably because of the compound data-class label. The paths above were computed locally from the same graph.
  • AWS defaults would blunt two findings at apply time. New S3 buckets enforce Block Public Access with ACLs disabled, so the public-read ACL would fail without explicit ownership controls. The RDS instance gets the VPC's default security group, which blocks inbound by default. The posture is still non-compliant, and either default is one change away from real exposure.
  • One claim in the fixture README is overstated. Federation uses https_web, which authenticates the partner bundle endpoint with Web PKI. That is weaker than https_spiffe but not unauthenticated, so it is rated medium here. The bundle endpoint on 8443 is also not opened by the security group.
  • The two IAM roles are not chained in code. The workload role reaches data through its own Resource:* grant. The admin-level exec role is reached through account-root trust: the deployer user, or any account principal allowed sts:AssumeRole.
  • Not run: DAST, behavioral red-team and canary episodes. There is no live agent endpoint to drive, so nothing is marked proven.
